# SAP Materials

This directory contains the public English SAP and appendices used to interpret
the study analyses.

- `SAP_v3.7_en.md`: English SAP v3.7.
- `appendices/v1.3/`: public script inventory, data dictionary, behavior-code
  rules, and appendix manifest.

The same inventory appendices are also copied under `data/script_inventory/` so
data users can find them without reading the SAP directory first.

# 動機づけ面接（MI）実践マニュアル（要約版）
*統合版の内容を、全体構成を維持して短縮*

---

## 0. このマニュアルの目的と使い方
- MIを「テクニック集」ではなく「対話の在り方」として実践する。
- 本人の内的動機とコミットメントを強める。
- 修正反射（Fixing Reflex）を自覚し、関係性と自律性を守る。
- 使い方: 1) 定義 2) スピリット 3) 4タスク 4) OARS/聞き返し 5) チェンジトーク/質問 6) 罠/実践フロー 7) 付録。
- 会話の焦点は「変化に関する言葉」に置き、チェンジトークを育てる。
- おすすめの読み順: 定義・スタイル → スピリット → 4タスク → OARS/聞き返し → チェンジトーク/質問 → 罠/実践フロー → 付録。

## 1. MIとは何か
- MIは、本人の「変わりたい」を見つけ育てる固有の対話スタイル。
- 対話スタイルは「指示」「追従」「ガイド」。MIはガイド。
- 最終決定権は本人にある（自律性尊重）。
- MIは「説得」でも「放任」でもない。
- 指示: 答えを提示しやすいが主体性を奪いやすい。
- 追従: 関係は保ちやすいが焦点を失いやすい。
- 重要なのは「相手を変える」ではなく、相手の中の「変わりたい」を育てること。

## 2. MIの精神（PACE）
- Partnership（協働）: 支援者は会話の専門家、本人は人生の専門家。
- Acceptance（受容）: 絶対的価値・正確な共感・自律性尊重・是認。
- Compassion（慈愛）: 支援者都合より本人の最善の利益。
- Empowerment（エンパワメント）: 欠けの注入より、既存の強み・資源を引き出す。
- 変容のパラドックス: 「ありのままが受け入れられた」と感じたとき変化しやすい。
- 修正反射（正そう・解決してあげようとする衝動）を避ける。
- 受容は同意ではない。理解の姿勢を保つこと。
- 是認は、努力・強み・価値観に光を当てて言語化する。
- 援助は「レスリング（力比べ）」ではなく「ダンス（共演）」として行う。

## 3. MIの4つのタスク（プロセス）
- Engaging（関わり）: 信頼関係の構築。
- Focusing（焦点化）: どこへ行くかの合意。
- Evoking（呼び起こし）: なぜ行くか（チェンジトーク）を広げる。
- Planning（計画）: どう行くか（具体行動）へ。
- 非線形が前提。停滞・不協和が出たら関わりへ戻る。
- 序盤20%は関わりに投資する。
- 階段を一直線に上るのではなく、必要に応じて戻る。
- 焦点化では「広げる→絞る」を意識する。
- 「階段をダンスしながら降りる」運用を許容する。

## 4. 基礎技術：OARS
- O: 開かれた質問（情報収集より内的世界の探索）。
- A: 是認（努力・強み・価値観の言語化）。
- R: 聞き返し（意味整理・焦点調整・変化促進）。
- S: 要約（チェンジトーク中心の「花束」）。
- 実務目安: 質問1に対して聞き返し2。
- 要約では維持トーク（雑草）よりチェンジトーク（花）を中心に束ねる。
- OARSは個別技法ではなく、関わりを深める一体運用。
- Yes/Noで終わる質問が続くと尋問化しやすい。
- 情報提供が必要なときは、Ask-Offer-Ask（許可→短い情報→反応確認）で行う。

## 5. 聞き返し（Reflective Listening）
- 対話には「意図→発話→受容→解釈」のズレが起こる。
- 聞き返しは、支援者の解釈を返して本人に検証してもらう行為。
- 単純反射: 言い換え・要点確認（安全だが多用で停滞）。
- 複雑反射: 感情・価値・意図を推測して返す（深まりを促す）。
- 段落の継続: 相手の「次の一文」を仮説で差し出す。
- 方向性のある聞き返し: 両価性ではチェンジトーク側を優先して拾う。
- 外れても訂正が起こり、本人の言語化が進む。
- 例: 「変えたいが今は難しい」には、変えたい側を丁寧に反射する。
- 例: 「分かっている、というところが大きいのですね。」
- 聞き返しの本質は、理解の輪を閉じること（返す→検証してもらう）。
- 複雑な聞き返しは「戦略的推測」。外れたときの訂正も、言語化の前進として扱う。

## 6. 是認（Affirmation）
- 是認は賞賛ではなく、価値あるものとしての尊重（Valuing）。
- 欠損モデルでなく資産フレーミングで見る。
- 単純な是認: 行動・事実への是認。
- 複雑な是認: 背後の資質・強み（アイデンティティ）への是認。
- ルール: 「私」を主語にしない（強みの所有権を本人に残す）。
- 例: 「私はすごいと思う」より「粘り強さがありますね」。
- 努力・工夫・価値観を具体化して伝える。
- 例: 「困難があっても、ここに来る行動を選ばれたのですね。」
- 例: 「ご自身にとって大切なものを守ろうとする誠実さが伝わります。」

## 7. チェンジトークを理解する
- チェンジトーク: 変化に向かう発言。
- 維持トーク: 現状維持に向かう発言。
- 目標は維持トークの否定ではなく、チェンジトーク比率を増やすこと。
- DARN（準備）: Desire / Ability / Reasons / Need。
- CAT（実行）: Commitment / Activation / Taking steps。
- D（Desire）: 「〜したい」
- A（Ability）: 「できそう／できたことがある」
- R（Reasons）: 「〜だから良い」
- N（Need）: 「〜しないとまずい」
- C（Commitment）: 「〜します」
- A（Activation）: 「やる気が出てきた／動き始めた」
- T（Taking steps）: 「もう始めた／手続きをした」
- 特にC（Commitment）は実行確度に直結しやすい。
- 人は「他人に言われたこと」より「自分の言葉」に説得されやすい。
- 維持トークは敵ではない。まず受け止め、整理し、再評価を支える。

## 8. チェンジトークを引き出す質問
- 質問の罠を避ける: 閉じた質問の連続は尋問化しやすい。
- 開かれた質問を使い、聞き返しを増やす（質問1:聞き返し2）。
- 質問は「情報」より「意味」「価値」「望み」を探索する。
- DARNに沿って問う（願望・能力・理由・必要性）。
- ルーラー（0〜10）では「なぜ0でないか」を問う。
- 極端の探索: 最悪/最善シナリオを想像して意味を言語化。
- 価値観探索: 理想の自分・大事なこととの接続を問う。
- Lending Change Talk: 一歩先の仮説を「断定せず」差し出す。
- 4点なら「なぜ0ではないか」を尋ね、10でない理由は掘らない。
- 例（Desire）: 「状況が変わるとしたら、どんな良いことがありますか？」
- 例（Ability）: 「これまでの経験で役立つ強みは何ですか？」
- 例（Reasons）: 「変えることに、どんな価値がありますか？」
- 例（Need）: 「このままだと困る点はどこにありますか？」
- 例（Values）: 「その選択が、あなたの大事にしていることとどう関係していますか？」

## 9. 維持トークと不協和（Discord）
- 維持トーク: 変化に対する迷い（アンビバレンスの一部）。
- 不協和: 関係悪化サイン（押しつけられ感・反発）。
- 不協和が出たら「横に泳ぐ（Swim Sideways）」。
- 変化推進を止め、関わりへ戻る。
- 有効: 自律性の強調、率直な聞き返し、焦点の再合意。
- 例: 「決めるのはあなたです」「押しつけられている感じがしたのですね」。
- 例: 「今この場で、何を話すのが一番役に立ちそうですか？」
- 維持トークは行動変化への迷い、不協和は関係性のズレとして区別する。

## 10. 陥りやすい罠と回避策
- 修正反射: 正しさで押すほど、相手は変わらない理由を強めやすい。
- 4つの罠: 専門家の罠 / 説得の罠 / 時間の罠 / 迷走の罠。
- 専門家の罠: 「私が答えを知っている」という態度。
- 説得の罠: 正論で押して心理的リアクタンスを生む。
- 時間の罠: 急いでEngagingを省く。
- 迷走の罠: 目的なく聴き続け焦点を失う。
- 避けたい質問: 「なぜ変えないのですか？」など維持トークを強制する問い。
- 自己開示はクライアント利益基準（真実性・無害性・有益性）。
- 許可のない助言・警告・説教は避ける。
- 回避の基本は、反射→要約→必要時に提案。
- 避けたい問いの例: 「リスクがどれほどか分かっていますか？」
- 避けたい問いの例: 「なぜ私の提案を試さないのですか？」

## 11. セッション設計：実践フロー
- 開始（Engaging）: 安心感と協働関係を作る。
- 焦点化（Focusing）: 広げる→絞る。
- 呼び起こし（Evoking）: DARNを増やしCATへの橋渡し。
- 計画（Planning）: 誰が・いつ・何をの一歩へ具体化。
- 終結（Summary）: チェンジトークを花束として返し、理解一致を確認。
- 例: 「今日まず扱うなら、どれが一番よさそうですか？」
- 例: 「実行できたと分かるサインは何ですか？」
- 例: 「変えるとしたら、どんな良いことがありそうですか？」
- 例: 「まずは、今の状況をあなたの言葉で教えてください。」
- 例: 「この時間で、どこまで進められると良さそうでしょう。」
- 計画フェーズ移行の目安: CAT（決意・意欲・一歩）が出てきたとき。

## 12. 実務チェックリスト（統合）
- スタイルはガイドになっているか。
- PACEを体現しているか。
- 受容の4側面を外していないか。
- 冒頭20%を関わりに投資したか。
- 修正反射に気づき手放したか。
- 質問偏重を避けたか（1:2の目安）。
- 是認で「私」を主語にしていないか。
- 複雑な聞き返しで「段落を継続」できているか。
- 維持トークと不協和を区別し、必要時に再エンゲージしたか。
- 要約でチェンジトークを中心に束ねたか。
- CATが出た時点で計画へ移る判断ができたか。
- 迷走時に焦点の再合意を取れたか。

## 付録A：質問テンプレート集（チェンジトーク誘発）
- Desire: 「本当は、どうなったら嬉しいですか？」
- Desire: 「理想に近づくとしたら、何が一番変わりますか？」
- Ability: 「今ある強みで、役立ちそうなのは何ですか？」
- Ability: 「できた経験があるとしたら、どんな時でしたか？」
- Reasons: 「変えることに、どんな価値がありますか？」
- Reasons: 「あなたにとって何が一番大切ですか？」
- Need: 「このままだと困ることは何ですか？」
- Need: 「先延ばしにすると、どんな影響がありそうですか？」
- Commitment: 「次にどうしたいと思っていますか？」
- Commitment: 「いつから、何をしますか？」
- Activation: 「何が後押しになりそうですか？」
- Taking steps: 「すでにやってみたことはありますか？」
- Taking steps: 「うまくいった部分はどこでしたか？」
- ルーラー追問: 「なぜその数字で0ではないのですか？」/「1つ上げるには？」
- ルーラー追問: 「0〜10でどのくらいですか？」

## 付録B：聞き返しテンプレート集（単純→複雑）
- 単純: 「〇〇ということですね。」/「今は△△が難しいのですね。」
- 複雑: 「〇〇も大事にしたい一方で、△△も守りたいのですね。」
- 価値接続: 「…だからこそ、納得できる形が必要なのですね。」
- 段落の継続: 「…もし現実的な方法が見つかれば、試してみたい思いもあるのですね。」
- 方向づけ: 「分かっている、というところが大きいのですね。」
- 願望の明確化: 「本当は、〇〇に近づきたい気持ちがあるのですね。」
- 自律性の尊重: 「誰かに決められるのではなく、自分で選びたいのですね。」

## 付録C：花束の要約テンプレート集
- 小さな花束: 「今出てきたのは、①〇〇を大切にしている、②△△が理由、の2点ですね。」
- 大きな花束: 「〇〇を大切にし、△△の理由で変化に価値を感じ、まず□□という一歩を考えているのですね。合っていますか？」
- 終結時は次回への接続と労いを短く添える。
- 大きな花束（詳細）: 「あなたは〇〇を大切にしていて、△△という理由で変化に価値を感じています。以前の経験から××はできる可能性があり、まずは□□という一歩を考えています。今の整理で合っていますか？」

## 用語集（最小限）
- MI: 変容と成長に向けた対話スタイル。
- スピリット（Spirit）: MIの根底にある態度。PACEで整理する。
- PACE: 協働 / 受容 / 慈愛 / エンパワメント。
- OARS: 開かれた質問 / 是認 / 聞き返し / 要約。
- 修正反射: 正しさで急いで解決したくなる衝動。
- 両価性: 変わりたい気持ちと変わりたくない気持ちの同居。
- チェンジトーク / 維持トーク / 不協和（Discord）。
- DARN-CAT: チェンジトークの分類（準備→実行）。
- 不協和: 支援者との関係性の悪化サインで、維持トークと区別が必要。
